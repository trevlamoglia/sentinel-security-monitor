# sentinel-security-monitor
A lightweight SIEM platform built with Python and MySQL to analyze security logs, detect suspicious activity, and generate alerts. Developed as a hands-on project combining software engineering and cybersecurity.


## Features to develop
- Log parsing and normalization
- Failed-login and brute-force detection
- MySQL storage for security events and alerts
- Python backend and REST API
- Web dashboard for viewing events
- Automated test and secure coding practices
